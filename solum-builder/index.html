Solum Builder

A circuit simulator for guitar-pedal builders that runs on your own computer. Draw a circuit, probe any point in it, turn its knobs and watch the frequency curve follow, check it against plain-English rules, and hear it through an amp model.

View on GitHub → How to install ↓

The Ibanez TS808 Tube Screamer, one of the 19 starter circuits, after a run: DC voltage at every node, and the probed point's gain, frequency curve and waveform.

On your computer

No accounts, no cloud. It is for one person on one machine.

Plain files

Your circuits are plain JSON files in a folder you choose.

19 starters

TS808, Big Muff, Fuzz Face, Rat, BD-2 and more. Open one, then save a copy to change.

Probe anything

Click any wire or part: waveform, harmonics and DC voltage, with gain, peaks, clipping and distortion.

Frequency

See what the knobs do

How much louder or quieter each frequency comes out at the probed point, from 10 Hz to 30 kHz, with its peak and corners marked. It follows the knobs as you turn them.

Part influence ranks the parts by how much they move the curve. Edit curve lets you drag a corner or a peak and changes the parts to match.

Bias & headroom

Know what clips first

Is each stage biased where it should be, which one clips first, and how hard do you have to play for it to happen?

The signal path is drawn as a chain from guitar to amp, with the level at every stage for a soft, medium and hard pick.

Audio

Hear it

A guitar recording through the circuit, then through a NAM amp capture and a cab IR if you add them. Switch between Dry, Pedal and a kept Snapshot while it plays.

Nothing to listen to ships with the app: you bring your own recording, amp captures and cab IRs.

Install

Run it in a few minutes

You need Docker (or Podman) with Compose, on an x86-64 or ARM64 machine, Apple Silicon included.

$ git clone https://github.com/pbexiga/solum-builder.git
$ cd solum-builder
$ cp .env.example .env
$ docker compose up

Then open http://localhost:8000. The first run builds the image, which takes a few minutes. With Podman, use podman compose.

The setup, updating, running from source and the full guide are in the README on GitHub.
